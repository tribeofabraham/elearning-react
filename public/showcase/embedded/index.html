Getting started with MIDI

This page stands in for someone else’s site. The quiz below is running in a frame, served from learn.tribeofabraham.com. Nothing about it changed to make this work: it’s the same build as the standalone quiz, placed here with one iframe tag.

MIDI is how a keyboard, a drum machine and a laptop agree on what’s being played. It doesn’t carry sound; it carries the performance: which note, how hard, when it stops. If you play in a band that uses backing tracks or a foot controller, MIDI is already in the room.

Before the workshop, try the short quiz below. It takes about five minutes, tells you why after each answer, and shows your score at the end.
