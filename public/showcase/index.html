Tribe of Abraham E-Learning

One module, shipped four ways. Same code every time.

A ten-question MIDI quiz, built once in React, delivered on its own, inside another site’s page, through a commercial authoring tool, and as a cmi5 lesson, each time reporting to a real learning record store.

The four deliveries

  1. 1 Hosted standalone

    On my own server, with no LMS involved.

    A small Node relay records each attempt as xAPI, so no LRS credentials ever reach the browser.

    Proves: the content doesn’t need a platform.

    Take the standalone quiz

  2. 2 Embedded

    The same build running in a frame inside someone else’s page.

    An ordinary iframe: the quiz sizes itself to the frame and tells the host page its progress and score.

    Proves: it drops into an existing site or portal with nothing changed.

    See the quiz embedded in another page

  3. 3 Lectora: SCORM 2004 + xAPI

    Published through a commercial authoring tool, reporting on both standards at once.

    The Lectora course hosts the quiz and passes the learner in; the score and pass or fail go to SCORM 2004 while the quiz records the full xAPI detail.

    This lets a scored React element drop straight into an authoring tool’s web object, as in Lectora or Storyline. The example here uses a demo version of Lectora Online.

    Proves: it survives the enterprise toolchain teams already own.

    Open the Lectora course in SCORM Cloud (it asks for a name and email first)

  4. 4 cmi5

    One address that scores when an LMS launches it and explains itself when it doesn’t.

    Proves: the LMS keeps launch, identity and the record; the content lives wherever you want, with no separate public build to keep in sync.

    When an LMS launches it:

    1. The LMS hands over a one-time sign-in and who the learner is.
    2. The lesson reads the LMS’s pass mark and the learner’s preferences.
    3. It reports to the LMS’s own LRS by the cmi5 rules: initialized, each answer, passed or failed, completed, terminated.
    4. It returns the learner to the LMS.

    Open the cmi5 lesson directly (a practice run)

All four run the same React code, the same ten questions and the same accessible screens. Only the way each one reports changes.
